# Metrics 0.27: Wire 0.15 native schema identity

Metrics' default-enabled `native-wire` metadata now implements the Wire 0.15
trait for aggregate, counter, summary, histogram and fixed-array report records.
Native schema consumers must select published Metrics `^0.27` and Wire `^0.15`
together. Updating a consumer's direct Wire dependency cannot
replace the Wire 0.14 trait implementation supplied by Metrics 0.26.

For Principal/Account schema composition, select canonical `ic-platform-types`
`^0.17`, or the matching `ic-platform` `^0.18` re-exports, with Wire's
`platform-types` feature. Those suppliers belong to the independent integration
fixture; Metrics itself adds no Platform, Types, runtime, endpoint or persistence
dependency. No `ic-wire-endpoint` dependency is required by these reports.

For example:

```toml
[dependencies]
ic-metrics = "0.27"
ic-wire = { version = "0.15", default-features = false, features = ["typescript", "platform-types"] }
ic-platform-types = { version = "0.17", default-features = false }
```

Update the consumer lock deliberately and regenerate/check native reports with
the matching schema suppliers. Numeric schemas, encoded bytes, declaration
order, typed refusals and admission rules are unchanged. Account subaccounts
retain their fixed-array representation: absent and explicitly zero remain
distinct. No retained-data conversion or new byte adapter accompanies this
adoption. Rust 1.99.1 remains the minimum on native and Wasm.

Arithmetic consumers disabling default features retain their existing API,
validated Serde and allocation-free behavior without Wire. Optional recording
stays separate, and Wasm excludes native metadata even with all features enabled.
Logging has no Wire dependency and requires no release for this adoption.

The [source fixture](../../qualification/wire-identities/README.md) qualifies
current Metrics source with published Wire/derive 0.15.0, Types 0.17.0 and
Platform 0.18.0. This uses a workspace-owned Metrics 0.0.0 copy, separately from
the actual registry consumer. [Qualification evidence](../../docs/evidence/wire-0150.md)
records the executed checks and supplier provenance.

The [frozen published consumer](../../qualification/wire-published/README.md)
selects actual Metrics 0.27.1/Logging 0.24.2 with
Wire 0.15.0/Types 0.17.0/Platform 0.18.0. Its catalog, lock and explicit CI intent
advance together after publication; registry-only acceptance passes. Downstream
schema consumers can now adopt this published pairing and
qualify their own reports. Arithmetic-only consumers need no Metrics/Wire trait
coordination. [Verified delivery](../../docs/evidence/wire-0150-delivery-20261102.md)
records the initial minor release, archive readback and actual published-consumer
checks. [Patch delivery](../../docs/evidence/flow-cleanup-delivery-20261102.md)
records the current Metrics/Logging patch pair and its registry acceptance.
