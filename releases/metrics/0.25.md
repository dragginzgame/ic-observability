# Metrics 0.25: Wire 0.14 native schema identity

The pending Metrics source selects Wire 0.14 for native aggregate, counter,
summary, histogram and fixed-array metadata. Align every schema supplier with
one Wire 0.14 trait identity before composing reports. A consumer's direct Wire
update cannot replace the Wire 0.13 traits supplied by published Metrics 0.24.
The package version remains maintainer-owned until release.

After Metrics 0.25 is published, native schema consumers select Metrics `^0.25`
and Wire `^0.14` together. Consumers composing Principal/Account schemas also
select canonical Types `^0.16` or matching Platform `^0.17` re-exports. Update
the consumer lock deliberately; a Wire-only update leaves Metrics 0.24's old
trait implementation in the graph. Arithmetic consumers disabling default
features retain their existing API and require no Wire pairing.

Wire 0.14's optional `platform-types` integration selects canonical Types 0.16.
The independent source qualification composes Types 0.16.0 and Platform 0.17.0
with the current Metrics source. Metrics itself gains no Platform, Types,
endpoint, runtime or stable-memory dependency.

Numeric schemas, encoded bytes, bounded admission and arithmetic APIs are
unchanged. Default-enabled `native-wire` remains native-only. Disabling defaults
retains validated Serde and arithmetic without Wire; Wasm arithmetic remains
independent even when all Metrics features are selected. Rust 1.91 remains the
minimum compiler.

The [source consumer](../../qualification/wire-identities/README.md) qualifies
the new graph. The [published consumer](../../qualification/wire-published/README.md)
deliberately retains Metrics 0.24.6 with Wire 0.13.5 and Types 0.15.1/Platform
0.15.2 until a released Metrics/Wire 0.14 graph is explicitly selected. Source
qualification does not establish registry publication or downstream acceptance.

Metrics is the only Observability package needing publication for the new
pairing. Logging has no Wire dependency and needs no release. After that Metrics
publication, advance the published consumer's Metrics, Wire, Types and Platform
catalog entries together, update its lock and run its explicitly versioned
acceptance command. Until then, the historical registry check cannot establish
Wire 0.14 compatibility for a future Metrics release.

[Focused qualification](../../docs/evidence/wire-0140.md) records the executed
source, historical registry, metadata and arithmetic-isolation checks.
