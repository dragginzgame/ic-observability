# Metrics 0.29 instrumentation boundary

Breaking source cut for
[#130 — Restrict Metrics to instrumentation](https://github.com/dragginzgame/ic-observability/issues/130).
Logging's contract and version are unchanged.

Metrics instruments the Canic application tree. It no longer exports general
ratio/rounding helpers, checked wide report-cohort accumulators, means, numeric
deltas/intervals or histogram reporting queries. Remove arithmetic/formatting-only
Metrics dependencies and keep those operations with their reporting owner.
Legitimate counters, observations, bounded recording, overflow quality and reset
semantics remain available. The [API inventory](../../docs/metrics-api.md) lists
all retained and removed public members and the concrete consumer repairs.

Recorder types no longer implement Serde and are not report DTOs. Canic's metrics
adapter owns the shared reporting endpoint, report DTOs and Wire/TypeScript
projection. Blob/IcyDB/Relay must separate internal instrumentation from their
report decoding/validation, preserving their own field shapes, bytes, numeric
quality and bounded admission. Existing deployed endpoints require their owning
explicit hard-cut treatment before removal; this producer cut does not remove one.

Storage adapters replace the four `Type::from_parts(...)` calls with
`ic_metrics::persistence::restore_{aggregate,counter,summary,histogram}(...)`.
Import `MeasurementStateError` and the borrowed histogram-bounds validator from
`ic_metrics::persistence`. Existing field arguments, validation semantics and
refusal priority are retained; only the explicit source boundary changes.
The adapter continues to own its durable codec, tags, schema and same-release
continuity. Do not change stored bytes, invent a reset or reinterpret retained
data merely to adopt these call paths. Qualify real retained-format fixtures at
Storage. Metrics itself has no durable-format version or migration to perform.

Both libraries have no production dependencies. Serde remains development-only
for negative API checks. Metrics still supports Rust 1.99.1, `no_std`, allocation-free
fixed recording and separately enabled `recording` heap retention. No Canic,
Wire, Platform, endpoint, timer or stable-memory dependency is added.

The producer's focused checks establish its API, recording and restoration
behavior. Issue #130 remains open until required consumer repairs and acceptance
are complete; a producer release or missing symbol alone does not complete it.
