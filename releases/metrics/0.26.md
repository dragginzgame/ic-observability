# Metrics 0.26 migration

The supported Rust minimum is now **1.99.1**, on both native and
`wasm32-unknown-unknown`. Update consumer builders and CI before adopting this
release. The workspace uses that same exact compiler for development and release.
This is a breaking support-policy change. Earlier published releases retain
their original support declarations.

No arithmetic, logging, schema or encoded-byte changes accompany this compiler
policy change. Dependency requirements and locked dependency graphs are unchanged.
See [compiler setup and qualification](../../docs/hosts.md#prerequisites-and-focused-checks)
and [the owning issue](https://github.com/dragginzgame/ic-observability/issues/124).
